## How to build it
The Xcode project is generated by **XcodeGen** from `SwingCaptureApp/project.yml`:

```bash
brew install xcodegen          # if not already installed
cd GolfLaunchMonitor/SwingCaptureApp
xcodegen generate
open SwingCapture.xcodeproj
```

(If you'd rather create the target yourself or drive `xcodebuild` directly,
that's fine too — whatever reliably gets it onto the device.)

Then:
- **Signing:** team **"Cockshire Services"**, automatic signing, a unique bundle
  ID like **`com.joshstarin.swingcapture`**.
- **Device:** must be a **physical iPhone** (the Simulator has no 240 FPS camera).
- On first install Josh must trust the developer profile: **Settings → General →
  VPN & Device Management → trust the team**.
- The app needs **camera + mic** permission (already declared in `project.yml`),
  runs in **landscape**, and saves clips to the app's Documents (file sharing is
  on, so they show in the Files app and the in-app share sheet).
